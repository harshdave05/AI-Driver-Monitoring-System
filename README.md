# AI Driver Monitoring System

An AI-powered real-time driver monitoring system built using YOLOv8, MediaPipe, Flask, and OpenCV.

## Features

* Drowsiness Detection
* Phone Usage Detection
* Smoking Detection
* Face Mask Detection
* WhatsApp Emergency Alerts
* Real-Time Monitoring

## Tech Stack

* Python
* Flask
* OpenCV
* YOLOv8
* MediaPipe
* Twilio
* Cloudinary

## Installation

```bash
git clone https://github.com/harshdave05/AI-Driver-Monitoring-System.git
cd AI-Driver-Monitoring-System
pip install -r requirements.txt
```

## Run the Project

```bash
python app.py
```
